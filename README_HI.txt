Bubble Blast Pro - Android Studio project

Is ZIP mein aapke Bubble Blast Pro HTML game ko Android WebView app mein wrap kiya gaya hai.
Yeh APK nahi hai; APK banane ke liye Android SDK/Gradle build ki zaroorat hai.

APK banane ka tarika:
1. ZIP ko extract karein.
2. Android Studio mein extracted BubbleBlastPro folder ko Open karein.
3. Android Studio ko Gradle sync aur SDK download/install karne dein.
4. Build > Build Bundle(s) / APK(s) > Build APK(s) par click karein.
5. APK app/build/outputs/apk/debug/app-debug.apk mein milega.

App ID: com.bubbleblastpro.game
Minimum Android: 6.0 (API 23)
Game data local WebView storage mein rahega. App uninstall/clear data se progress delete ho sakti hai.
Rewarded ads abhi integrated nahi hain.
